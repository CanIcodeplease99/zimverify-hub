# 📱 ZimVerify Mobile App Installation Guide

## Overview
ZimVerify is a Progressive Web App (PWA) that can be installed on your mobile device for a native app-like experience with offline capabilities.

---

## 🍎 **iOS Installation (iPhone/iPad)**

### Prerequisites
- iOS 11.3 or later
- Safari browser (required for installation)

### Installation Steps:

1. **Open Safari**
   - Launch Safari browser on your iPhone/iPad
   - Navigate to: `https://b065e4fd-8e1e-4905-9803-383c13605224.preview.emergentagent.com`

2. **Access Share Menu**
   - Tap the **Share** button at the bottom center of Safari
   - (The box with an arrow pointing up)

3. **Add to Home Screen**
   - Scroll down in the share menu
   - Tap **"Add to Home Screen"**

4. **Confirm Installation**
   - You'll see the ZimVerify icon and name
   - Tap **"Add"** in the top right corner

5. **Launch the App**
   - Find the ZimVerify icon on your home screen
   - Tap to open the app

### iOS Features:
✅ Works like a native app
✅ No Safari UI (full screen)
✅ Appears in app switcher
✅ Offline access to cached data
✅ Fast launch times

---

## 🤖 **Android Installation**

### Prerequisites
- Android 5.0 (Lollipop) or later
- Chrome, Edge, or Samsung Internet browser

### Installation Steps (Chrome):

1. **Open Chrome Browser**
   - Launch Chrome on your Android device
   - Navigate to: `https://b065e4fd-8e1e-4905-9803-383c13605224.preview.emergentagent.com`

2. **Install Prompt (Automatic)**
   - You may see a banner at the bottom: "Install ZimVerify?"
   - Tap **"Install"** or **"Add"**

3. **Manual Installation** (if no banner appears):
   - Tap the **three dots** (⋮) menu in the top right
   - Select **"Add to Home screen"** or **"Install app"**
   - Tap **"Install"** to confirm

4. **Launch the App**
   - Find the ZimVerify icon in your app drawer
   - Tap to open

### Android Features:
✅ Native app experience
✅ Push notifications (when enabled)
✅ Background sync
✅ Offline functionality
✅ No browser UI
✅ Fast performance

## 🔧 **Troubleshooting**

### iOS Issues:

**App not installing?**
- ✅ Make sure you're using Safari (not Chrome or other browsers)
- ✅ Update iOS to the latest version
- ✅ Clear Safari cache: Settings → Safari → Clear History and Website Data

**App not opening?**
- ✅ Delete and reinstall from home screen
- ✅ Check if you have storage space available

### Android Issues:

**No install prompt?**
- ✅ Check if you're already on the latest version
- ✅ Clear Chrome cache: Settings → Privacy → Clear browsing data
- ✅ Try using Chrome Beta or Edge browser

**App crashes?**
- ✅ Update Chrome/browser to latest version
- ✅ Clear app data: Settings → Apps → ZimVerify → Clear Data
- ✅ Reinstall the app
